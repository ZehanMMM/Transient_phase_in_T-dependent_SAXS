# 仅修改转动熵：face轴向自由，tip三维自由

基于用户标注的“再加入旧版转动熵”版本，而非之后的降温历史版本。
保留20 s固定几何64态Neel动力学，各温度从均匀初态独立开始。
不改变Udd、dipole取向熵、概率分布、内部各向异性势垒或vdW。
前两阶段的主曲线完全不变，只有第三阶段的几何转动熵项改变。
旧图保留在上一级目录，本目录是单独输出。

## 转动允许范围

以单粒子完整SO(3)转动空间为归一化参考，假设两个粒子受到独立局部姿态约束。

    Delta F_rot = -2 kBT ln(f)

tip三维自由旋转，因此f_tip=1，转动约束自由能为0。
这表示相对于自由参考态没有熵损失，不表示其绝对转动熵为0。

face可绕两质心连线旋转完整2pi，只约束某一等价<100>面法向与连线对准。
保留原2度倾斜容差theta，每个圆锥球面占比为(1-cos(theta))/2，6个等价面给出

    f_face = 6 (1-cos(theta))/2 = 3(1-cos(theta))
    Delta F_rot,face / (kBT) = -2 ln[f_face] = 12.609592

不能把旧24个配准姿态的twist区间直接扩到2pi，否则会重复统计四重轴向对称。
face twist完全自由后不再使用旧的+/-5度限制。
严格0度倾斜容差的取向域测度为0，会给出发散的熵代价。
2度是未实测的几何容差假设，第三阶段能量绝对位置依赖此参数。

## 解释范围

这是因子化转动熵的敏感性修改，并非转动与磁矩共同演化的自洽模型。
三维自由的刚体转动实际可能改变实验室磁矩分布，但本次根据“只修改转动熵”
的范围保持磁模型不变。因此低温tip磁能近零的旧动力学行为也未被修正。
自由转动不保证全过程维持严格尖角接触，真实接触势与转动势垒没有计算。
此自由能包含的项不完整，不能由两条曲线直接认定胶体或聚集体相稳定性。
