# Face轴向转动、tip三维自由转动的三阶段计算

## 为什么本版需要重算Udd

上一版在每个温度从随机64态开始，只求Néel重排。整体转动只是事后熵项，
没有改变磁矩排列，所以低温能量接近零。这不是包含机械转动的预测。
本版在三个阶段都加入允许的快速机械转动，同一概率分布分别用于U和F。
三个图的变化只来自所显示的熵项，不是在第三图才打开磁矩对齐。

采用用户新的约束：face只允许绕中心连线转动，tip允许三维自由转动。
假设这些允许的机械转动比20 s快，先对快变量做条件平衡平均，再计算
剩余慢变量的Néel演化。这是绝热消去近似，不是显式20 s Brownian轨迹。
原有hexane自由Brownian时间为约0.8至4微秒，但真实接触处的旋转摩擦、
势垒未知，故这一时间尺度分离仍需实验验证。

## Face：绕[100]轴连续转动

磁矩在体坐标下仍位于<111>易轴。刚体绕x轴转动不会改变sx，但会改变
横向磁矩的方位角。定义a=sign(s1x*s2x)=+1或-1，phi为两个横向磁矩相对角。

    C = mu0 mu^2/(4 pi r_face^3)
    J = 2 C/3
    Edd(a,phi) = -J a + J cos(phi).

相对角的归一化配分函数为I0(J/kBT)，I0为第一类修正贝塞尔函数。

    f_a = -J a - kBT ln I0(J/kBT)
    u_a = -J a - J I1(J/kBT)/I0(J/kBT).

f_a为给定慢变量a后的条件自由能，u_a为条件平均偶极能。即使a还未完成
Néel重排，横向分量也会通过绕轴转动形成吸引，所以低温Udd不再为零。

64个易轴组合按a分为各32态。同组态由对称性等权，可以严格约化为a的
二态占据概率P(t)=Pr(a=+1)。初态P(0)=1/2。改变任一颗粒的x符号才能切换a，
每个颗粒有1条这样的相邻路径。改变y/z符号只改变快方位角，不改变a。

跳跃时sx=0的<110>鞍点，其快变量自由能为

    f_saddle = -kBT ln I0[C sqrt(2/3)/(kBT)].

采用简化绝热过渡态速率

    k_(a -> -a) = 2/(3 tau0) exp[-(DeltaEani + f_saddle - f_a)/(kBT)].

系数2为两个颗粒均可翻转x符号。3来自原有单颗粒三条相邻逃逸路径的
尝试频率分配。该速率是新的模型近似，不是原64态生成矩阵原封不动复用。
它满足相应的详细平衡，但未计算磁场引起的鞍点移动及速率前因子变化。

    Peq = 1/[1+exp(-2J/kBT)]
    P(t) = Peq + (1/2-Peq) exp[-(k_plus+k_minus)t].

直接计算并在0至20 s平均

    U(t) = -J[2P(t)-1] - J I1/I0
    F_orientation(t) = -J[2P(t)-1] - kBT ln I0
                       + kBT[P ln(2P)+(1-P)ln(2(1-P))].

平均能量解析积分，非线性熵项采用自适应积分。没有用平均概率代替
自由能的时间平均。没有加未弛豫penalty。

## Tip：三维自由转动

即使内部磁矩锁定在某条易轴，三维刚体转动也能使实验室坐标中的磁矩
方向遍历球面。对两个球面的偶极能直接做联合Boltzmann平均。
令lambda=C_tip/(kBT)，u为第一个磁矩与中心线夹角余弦，v=sqrt(1+3u^2)，
则对第二个磁矩积分后

    Z_tip = integral[-1,1] sinh(lambda v)/(lambda v) du/2
    F_orientation = -kBT ln Z_tip
    Udd = -C_tip <v [coth(lambda v)-1/(lambda v)]>_weighted.

采用160阶Gauss-Legendre求积。绝热极限下该磁自由能与20 s无关，
因为其已能通过自由刚体转动弛豫，而不是依赖内部Néel跃迁。
这不是手动将tip设为最低能-2C，热涨落始终保留。

重要几何限制：保持同一对角线tip接触与允许刚体三维自由转动一般不兼容。
本版tip标签表示固定原tip中心距离下的自由旋转分支，不保证每个姿态
仍然是tip-to-tip接触。中心距固定为28.51666 nm，未联立优化接触距离。

## 两种取向熵怎样避免重复

图2中的DeltaS_orientation是相对于“各分支允许域内无磁相关分布”的熵差。
它包含磁矩相关性，以及形成磁相关性所需的机械取向概率变化。
因此不能将它称为纯粹的内部Néel熵。

图3只额外计入允许域的几何测度，而不再次计算全部机械转动熵。
tip完整SO(3)可访问，因此f_tip=1，额外几何约束代价为零。
face的轴向twist完全自由，只限制面法向与链接轴对准。
以2度小圆锥正则化严格零宽度限制，6个等价<100>法向给出

    f_face = 6 (1-cos(theta))/2
    F_constraint,face = -2 kBT ln f_face = 12.609592 kBT.

theta=2度是未测定的角度容差，不是实验拟合。磁积分采用精确轴向模型，
小圆锥只用于几何熵正则化，忽略2度倾斜对磁能的微小修正。
本版不再使用旧的face24配准twist半宽或tip8体对角线自由twist计数。
若两粒子的姿态不是独立受局部约束，则-2lnf的独立约束假设也需修改。

取向熵不是零，所以能量图和自由能图不相同。低温tip在本模型下保持

tip不再有额外几何代价，当前温区tip分支都更低。这不是完整相图预测。

## 保留的参数和未包含部分

16 nm核心、Ms=2.85e5 A/m、TB=250 K、100 s标定、tau0=0.98 ns、CV=0。
纯立方势垒DeltaE=Kc V/12及常数Kc=2.5633e5 J/m3假设沿用。
内部连续偏离易轴、样品Ms(T)与多粒子局域场尚未计算。
vdW沿用名义姿态4^3体素结果，已知未收敛且未包含姿态依赖。
配体/溶剂有效势、位置熵、SC多粒子约束以及真实转动势垒未包含。
因此assembly_free_energy_J保持NaN。

测试包含自由偶极零耦合与弱耦合极限、80/160阶求积收敛、U对配分函数
温度导数的热力学一致性、face短/长时间极限，以及三个阶段差值的逐项记账。
原始研究背景：https://arxiv.org/abs/1403.6427。
