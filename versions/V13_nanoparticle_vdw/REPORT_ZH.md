# 纳米颗粒 vdW 模块：结果摘要

完整论证与全部数字见 `FINDINGS.md`，接口交付说明见 `INTEGRATION.md`。
所有能量默认是**一对颗粒的完整相互作用 U_pair**；标注 "per particle" 的是
U_pair/2，仅对孤立双颗粒体系有意义。

## 先说文献核对的两个前提

`references/` 里只有 `singh.sm.pdf`。**Lee–Arya SI 不在本仓库中**，全文搜索
"Arya" 只在三篇无关缓存论文的参考文献里出现。因此本阶段没有任何结论依赖
该文献；若它约束排斥项形式、配体厚度或 Hamaker 常数，这些点仍然未定。

现有代码不是三个独立模型。`geometry_model.py` 是唯一的共享库，其余是入口
脚本。`pair_energy_model.py` **不是**能量模型，它只提供己烷黏度和 Brownian
时间。`finite_window_rotational_entropy.py` 不直接调用任何几何函数。

## 一、文献复现程度

**式 4 的函数形式是对的，印出来的常数不对。**

| | ε₁ | ε₂ | β (nm) | 曲线 rms | 势阱 |
|---|---|---|---|---|---|
| 文献原值 | 130 | 290 | 9.56 | — | **任何间距都没有** |
| 本项目校准（SI 网格） | 33.752 | 94.797 | 7.0375 | 0.0574 kcal/mol | (2.9921 nm, −2.3464 kcal/mol) |

- 用文献原值直接算：U_pair(2.99 nm) = **−23.884 kcal/mol**，比目标深 10.3 倍，
  且曲线单调，**没有极小值**。
- 校准后 rms 0.0574 kcal/mol 已达到数字化噪声底（线宽半高 0.0597），势阱位置
  误差 +0.0021 nm，深度误差 −0.016 kcal/mol。
- 但势阱附近本重构比文献曲线低约 0.14 kcal/mol（6%）。这是不知道作者节点
  坐标的代价，也是复现精度的诚实度量。

**为什么 β = 9.56 nm 不可能出势阱（定量结论）**

写 U_pair = |U_attr|·(x − 1)，x = U_rep/|U_attr|。ε₁、ε₂ 是线性前因子，所以 x
的形状只由 β 决定。实测：x 在 **间距 3.000 nm** 处取极大，正是文献势阱位置，
说明 β 与 ε₂/ε₁ = 2.231 把平衡点放对了；但极大值只有 **0.455**，排斥项差
2.197 倍。因为 x < 1 处处成立，U_pair 处处为负且单调。把 ε₂ 放大到 637.07 使
x 峰值恰为 1，得到的是 3.000 nm 处一个高度为 0 的**极大**加上 6.5 nm 处一个
−0.90 kcal/mol 的次级极小，不是文献的势阱。**固定 β = 9.56 nm 时，任何 ε₂
都给不出 2.99 nm 处 −2.33 kcal/mol 的简单势阱。**

**更重要的发现：文献势阱是离散化产物**

排斥积分有上界 ε₂K_W·S/β⁸ = 913.84 kcal/mol；吸引双重体积分在接触处按 1/D²
发散（平行平板 Hamaker 极限）。实测 U_attr×D² 在 D = 2 → 0.25 nm 区间基本为
常数，而 U_rep 饱和在 145 kcal/mol 附近。所以**收敛后的式 4 对任何
(ε₁, ε₂, β) 都是一路吸引到接触，只有硬核能定义接触距离**。27 单元求和掩盖了
这一点：两颗相切颗粒的最近体积单元中心仍相距 a/3 = 4.4567 nm。收敛验证的每
一个加密层级都**没有**势阱，只有 SI 的 27/386 网格有。

## 二、需要多少积分节点

| 积分 | 每颗粒节点数 | 精度 |
|---|---|---|
| 表面（`exact_surface`） | 216 (6×6²) | 0.1 % |
| 表面（`exact_surface`） | 384 (6×8²) | 0.002 % |
| 体积（Cartesian） | 1728 (12³) | 2.99 nm 间距 0.86 % |
| 体积（Cartesian） | **8000 (20³)** | **2.99 nm 0.13 %，1 nm 0.50 %** |
| 体积（Cartesian） | 13824 (24³) | 2.99 nm 0.030 %，1 nm 0.11 % |

**生产网格：Cartesian n = 20（8000 体积节点）+ facegl n = 32（6144 表面节点），
`r2_mode='exact_surface'`**，约 2 s/对。

两条必须记住的规则：

1. **径向规则在 2 nm 以下不能用。** 8192 节点时 1 nm 面对面误差 4.9 %、1 nm
   角接触 4.1 %，而 Cartesian 8000 节点分别是 0.50 % 和 0.016 %。原因是结构性
   的：Gauss–Legendre 节点向 x = ±a/2 聚集，正对着 1/r₁⁶ 被积函数集中的薄层。
2. **参考解必须同族。** 我第一次用径向规则当参考，得到 1 nm 处 5.7 % 的"误差"，
   那是两种规则的互差而不是收敛性。已改用 Cartesian n = 26 / n = 28 作参考并
   记录这次更正。

`r2_mode='nearest_element'`（SI 字面读法）**不收敛**到连续极限：6144 节点时仍
差 0.29 %，且随伙伴网格的疏密变化。只有 `exact_surface` 是与网格无关的定义。

## 三、16 nm 颗粒在 3 nm 间距

A = 2.0×10⁻²⁰ J，SI 网格校准常数，迁移方案 3，T = 298.15 K，中心连线 [100]，
中心距 19.000000 nm：

| 分量 | kcal/mol | J | kBT |
|---|---|---|---|
| U_attr | −14.6364 | −1.01689×10⁻¹⁹ | −24.703 |
| U_rep | +11.6771 | +8.11288×10⁻²⁰ | +19.709 |
| **U_pair** | **−2.9593** | **−2.05601×10⁻²⁰** | **−4.995** |
| U_pair/2 | −1.4797 | −1.02800×10⁻²⁰ | −2.497 |

其他方向：[110] −1.4675 kcal/mol = −2.477 kBT；[111] −0.9262 kcal/mol =
−1.563 kBT。300 K 时 [100] 为 −4.964 kBT。

相对转动（[100] 连线，3 nm 间距）：同向 −4.995 kBT；绕 [100] 扭 45° −5.842
kBT；绕 [001] 倾 15° −5.082 kBT（中心距需增大 1.02 nm）；绕 [001] 转 90°
与同向逐位相同，这是立方对称性的自检。

**中心距必须重解。** 3 nm 间距下超椭球与旧圆角立方体的中心距差：[100] 0，
[110] −1.226 nm，[111] −2.441 nm（16 nm）；19.5 nm 时 [111] 差 −3.455 nm。

## 四、参数迁移后势阱在哪里

| 边长 | 方案 1 | 方案 2 | 方案 3（推荐） |
|---|---|---|---|
| 13.0 nm | 无 | 2.9093 nm / −2.2515 | 3.3001 nm / −1.74945 |
| **16.0 nm** | 9.727 nm / −0.341（次级、虚假） | 3.5807 nm / −2.2515 | **3.6224 nm / −3.21876** |
| 19.5 nm | 无 | 4.3640 nm / −2.2515 | 3.9732 nm / −4.92141 |

深度单位 kcal/mol。

- **方案 1（SI 字面迁移）在参考尺寸之上失效。** K_W ∝ a⁶，而表面积分已经带
  a²，所以排斥项 ∝ a⁸。16 nm 和 19.5 nm 在 3 nm 间距处变成**净排斥**
  （+30.8 和 +211.8 kBT）。固定链长的配体层不可能有随核尺寸八次方增长的
  位阻能。
- **方案 2 是严格几何相似。** β ∝ a 时全部长度同步缩放，势能完全不变：势阱
  深度三个尺寸完全相同，位置严格 ∝ a（= 0.22374a）。数学上干净，但只能当敏
  感性分析——它要求配体层随核同比增厚，实际并非如此。
- **方案 3 冻结排斥前因子**（ε₂K_W 固定在 13.37 nm / 3 kcal/mol 参考），使
  E_rep ∝ a²。势阱随尺寸变深、绝对位置外移（3.300 → 3.622 → 3.973 nm），但
  相对位置内移（0.2539 → 0.2264 → 0.2038 a），这正是固定厚度壳层套在增大的
  核上应有的行为。**推荐用方案 3。**

适用限制：常数只在 a = 13.37 nm 单一尺寸、单一网格上拟合过，SI 没有给出任何
尺寸依赖信息，所以三个方案是同一次拟合的三种外推，不是三个预测。**不要要求
所有尺寸的势阱都落在 2.99 nm。**

尺寸趋势还取决于比较基准：固定物理间距 3 nm 时 U_pair ∝ a^2.02，固定相对间距
D/a = 0.1875 时 ∝ a^2.98，两者相差整整一个 a 的幂次。

整体能量增强用单一无量纲因子 s（1、2、5）乘完整势能，ε₁ 与 ε₂ 从不分别放大；
单元测试强制 s 对两项等比作用。

## 五、与旧模型的对照与效应分解

相同 Hamaker 常数、ε₁ = 1、无排斥、3 nm 间距、16 nm：

| 方向 | 旧模型 R / U | 超椭球 R / U | 比值 |
|---|---|---|---|
| [100] | 19.0000 nm / −4.8834×10⁻²¹ J | 19.0000 nm / −6.1410×10⁻²¹ J | 1.258 |
| [110] | 24.3848 nm / −9.2615×10⁻²² J | 23.1587 nm / −1.3569×10⁻²¹ J | 1.465 |
| [111] | 28.5167 nm / −2.4532×10⁻²² J | 26.0760 nm / −4.4736×10⁻²² J | 1.824 |

逐项分解（16 nm，3 nm 间距，[100]，298.15 K）：旧模型 −1.1863 kBT → 形状改变
−0.44 → 积分精度 +0.14 → ε₁ 能量标度 −19.65 → 排斥项 +38.34（方案 1）或
−24.71（方案 3）→ per-particle 折半。**主导效应是 ε₁ 能量标度和排斥项**，形状
改变和积分精度都是小量；pair/per-particle 只是因子 2，单独列出以免被当成物理
效应。

**常数与网格绑定**：同一组常数从 27/386 网格换到收敛网格，吸引项乘 **2.034**
（三组常数完全相同，因为 ε₁ 是线性前因子），排斥项变化在 2 % 以内，且收敛网格
上三组常数都没有势阱。

## 六、验证

`outputs/validation/D_validation.json`：**34 项检查，0 项失败**。
`pytest -q tests`：**46 项通过**。

关键项：颗粒交换对称 3.0×10⁻¹⁶；整体平移 2.1×10⁻¹⁴、整体转动 2.2×10⁻¹⁵；GJK
与解析支撑公式在 ⟨100⟩⟨110⟩⟨111⟩ 上差 6.2×10⁻¹⁵ nm（支撑高度精确等于 a/2 的
1、2^(1/3)、3^(1/3) 倍）；点到体距离双边证书 7.1×10⁻¹⁵ nm；体积权重和 2.2×10⁻¹⁶，
所有节点严格在体内（精确边界规则不会把边界处的不完整 voxel 当成完整的）；表面
权重和 4.3×10⁻⁶；386 个表面单元由 8×8×8 立方格点精确给出。

远场律独立解析验证：
U_attr = −ε₁(A/π²)V²/R⁶·[1 + 2.25(a/R)² + O((a/R)⁴)]，其中 2.25 = 30⟨x²⟩/a²，
而 ⟨x²⟩ = 3a²/40 是本体的闭式二阶矩。实测标度余量 2.2577（R/a = 80），拟合指数
6.00153。

重叠由 GJK 单独禁止并返回 +inf。软排斥项在 10⁻⁴ nm 间距时只有 148.9 kcal/mol，
有界，**单靠它挡不住穿透**——这是硬核必须独立存在的数值证据。

工作过程中有两处更正，因为它们改变了结论而不只是数位：点到体投影最初用法向
不动点迭代，在近平面上会振荡，已改为批量阻尼 Newton 解 KKT 方程（精度 10⁻¹⁴ nm，
快 17 倍）；`R − 2h(d)` 最初被当成通用解析基准，它只在对称方向精确，一般方向
只是下界——GJK 是对的，基准是错的。

## 七、接口需要改什么

整个 vdW 接触面只有 `geometry_model.py` 里**两个函数**：
`center_distance_at_gap_m` 和 `pair_vdw_energy_J`。替换它们，所有入口脚本自动
跟随。必须做的五处签名或行为改动、体积改变对 M_sV 与 K₁V 的连带影响
（体积 −9.90 % → m_s −9.90 % → E_dd −18.83 %，反推的各向异性常数 +10.99 %）、
各向异性符号约定（E_ani = K₁V(αx²αy²+αy²αz²+αz²αx²)，K₁ < 0；现有代码存的是
−K₁，转换时不翻符号会颠倒易轴难轴）、以及本征 K₁ 与有效势垒必须分开存放
（ZFC/FC 反推给出 |K₁| = 2.845×10⁵ J/m³，是室温块体值 1.25×10⁴ J/m³ 的
**22.8 倍**，不可能全部是本征磁晶各向异性），详见 `INTEGRATION.md`。
